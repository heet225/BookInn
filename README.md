BookInn is a full-stack web application designed to help users easily discover, list, and manage hotel and room bookings. The platform allows users to browse available accommodations, view detailed information, and securely make reservations through a simple and user-friendly interface.

The project is built using Node.js, Express, MongoDB, and EJS, following the MVC architecture. It includes features like user authentication, session handling, image uploads, and database-driven listings to provide a real-world booking system experience.

BookInn aims to simulate a modern hotel booking platform where users can register, log in, explore rooms, add new listings, and manage their bookings efficiently.

This project was developed to practice and demonstrate full-stack web development concepts such as backend APIs, database management, authentication, and dynamic UI rendering.


✨ Features

User authentication (Sign up, Login, Logout)

Secure session management using MongoDB

Browse hotel and room listings

View detailed information for each listing

Add, edit, and delete property listings

Upload and manage images using Cloudinary

Search and filter accommodations

Responsive and user-friendly UI

Protected routes for authenticated users

Error handling and form validation
